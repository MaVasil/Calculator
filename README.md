
# 🧮 Scientific Calculator (Web App)

A fully functional **Scientific Calculator** built using **HTML, CSS, and JavaScript**.  
This project performs both basic arithmetic and advanced mathematical operations directly in the browser.

---

## 🚀 Features

### ➕ Basic Operations
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Percentage (%)

### 🧠 Scientific Functions
- Trigonometric functions: `sin`, `cos`, `tan` (in degrees)
- Logarithmic functions: `log`, `exp`
- Square root (√)
- Power (x^y)
- Factorial (n!)

### 🔢 Constants
- π (Pi)
- e (Euler’s number)

### ✏️ Controls
- Clear display (C)
- Backspace (⌫)
- Real-time input display
- Error handling for invalid expressions

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## ▶️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/MaVasil/Calculator.git
````

2. Navigate to the project folder:

   ```bash
   cd Calculator
   ```

3. Open `index.html` in your browser

---

## ⚠️ Notes

* Trigonometric functions use **degrees (not radians)**
* Factorial works only for **non-negative integers**
* Invalid inputs will display `"Error"`
